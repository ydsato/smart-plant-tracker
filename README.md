# 🌱 Smart Plant IoT Monitoring System
An IoT-based plant monitoring system developed as a 3rd Year Academic Project. It collects environmental data through connected sensors and displays real-time readings using a desktop monitoring dashboard.

The system monitors temperature, humidity, soil moisture, and light conditions to help users observe their plants' environmental conditions.

# Features
➤ Temperature Monitoring – Measures surrounding temperature.

➤ Humidity Monitoring – Monitors environmental humidity.

➤ Soil Moisture Monitoring – Measures soil moisture levels.

➤ Light Detection – Detects surrounding light conditions.

➤ Real-Time Data Updates – Sends sensor readings to a database.

➤ Data Visualization – Displays historical sensor readings through graphs.

➤ System Activity Log – Displays sensor updates and connection status.
